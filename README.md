## 📖 Overview

**Gardenly** is an e-commerce web application for buying and selling **plants, seeds, pots, and gardening accessories**. It bridges the gap between plant enthusiasts, sellers, and experts, providing a unified platform to buy, learn, and grow.

Our mission is to make green living accessible and convenient for everyone by offering a variety of eco-friendly products, expert guidance, and nationwide delivery.

## ⚙️ How to Run (Locally)

### Prerequisites
- Install **Node.js** and **npm**
- Install **MongoDB** or create a **MongoDB Atlas** account
- Clone this repository  
  git clone https://github.com/SriHarshaRajuY/gardenly.git
  cd gardenly


STEPS

1) Install dependencies

npm install


2) Create a .env file in the root directory and include:

PORT=7000
MONGO_URI=mongodb://127.0.0.1:27017/gardenly

3)Run the server

npm start


4)Visit the app in your browser:

http://localhost:7000


🧩 Dynamic & API Features

Dynamic Rendering: EJS templates render real-time data for sellers and buyers.
